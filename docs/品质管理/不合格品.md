# 不合格品

> "不合格品列表"位于品质管理板块，来源于：1.入库检，成品检质检时不合格审批的操作（整批退，不合格退，特采，挑选使用，返工返修，让步，报废） 2.返工返修数据送检

#### 1.数据筛选

* 数据筛选：支持编号，来源（成品检，入库检），单号，相关方，产品/型号规格，不合格处理，检验员，时间的查询


#### 2. 复检

* 对返工返修的数据进行送检后的复检操作

#### 3.复检结果

* 点击可查看人员所复检的详细情况


#### 4.检验报告


* 点击可查看品质检验时所上传的检验报告



#### 5.检验结果

* 点击可查看品质检验时所输入的检验结果
