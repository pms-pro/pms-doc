# 生产成本

> "生产成本列表"位于财务管理板块，在"生产成本列表中可设置相对应的成本" 

#### 1.编辑成本

* 鼠标悬浮在人工成本，设备成本，辅材成本，检验成本，下方相对应的表字段中，默认是0，悬浮出现编辑图标可点击编辑成本或双击编辑成本

#### 2.状态

* 启用代表可以使用，停用代表不可使用

#### 3. 设置成本

* 点击设置成本按钮设置成本

  -选择成本（人工成本,设备成本，辅材成本，检验成本）

  -点击绿色三个点图标可添加新的选择框

  -可选择加某成本或减某成本

  -最后可手动输入自定义钱数

#### 4.详情

* 点击详情可查看成本的变更记录

* 如果更改了成本设置，会产生记录到详情中查看


#### 5.设置人

* 设置完成本后，页面显示设置人员，鼠标悬浮人员名称可查看人员的基础信息（项目，部门，电话）


![如图所示](../file/cw-sccb1.png)


#### 6.批量编辑

* 先勾选序号前的勾选框触发批量编辑按钮

* 点击批量编辑按钮可编辑所选的工序

#### 7.批量设置成本

* 先勾选序号前的勾选框触发批量设置成本按钮

* 点击批量设置成本按钮可设置所选工序的成本
