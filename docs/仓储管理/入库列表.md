# 入库列表

> "入库列表“位于仓储管理板块
> 
> 1.采购管理的 ”缺料列表“ 中收货以后带入过来的，包含产品，物料，在入库列表中需要去分发、入库。
>
> 2.成品检验、入厂检验、过程检验、中员工检验完成

## 入库任务
* 默认入库界面展示“入库任务”页面，也可点击入库任务菜单栏进入

#### 1. 订单交期

* 点击后可查看订单交期详情、物料明细、生产进度详情以及任务明细
* 可以通过任务明细中生产进度查看对应编号的进度详情

#### 2. 生产进度

* 点击后可查看订单交期详情、物料明细、生产进度详情以及任务明细
* 可以通过任务明细中生产进度查看对应编号的进度详情

![如图所示](../file/cc-rklb.png)

#### 3. 入库

* 点击入库按钮，可查看入库数据，支持下载/打印，可对其进行选择入库
* 点击申请入库量可查看该物料的入库批次详情
* 点击入库情况可查看该物料的入库记录详情
* 点击入库操作，选择仓位填写入库量

  -可添加多个仓位设置，点击红色删除图标可删除

  -点击提交按钮，可完成入库

![如图所示](../file/cc-rklb2.png)


#### 4.新增

* 点击新增，进入新增页面
* 查找物料中输入查询条件，点击检索
* 选中需要的数据，添加仓位和入库量

![如图所示](../file/cc-rklb3.png)


## 入库明细

* 可在此页面查看采购/生产入库的明细记录

#### 1.导出

* 选中导出数据，选择导出方式
